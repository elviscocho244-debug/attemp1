Código que
se reutiliza.

Define una función una vez y úsala en todos tus proyectos. ReuseKit la almacena lista para importar.

Probar ahora →
utils/helpers.py 
# ✦ Guardado en ReuseKit
from reusekit import snippet

# Función reutilizable
@snippet(tag="math")
def calcular_promedio(lista):
    if not lista:
        return 0
    return sum(lista) / len(lista)

# Importar en otro proyecto
from reusekit.lib import calcular_promedio

resultado = calcular_promedio([8, 9, 10, 7])
print(f"Promedio: {resultado}")  # → 8.5
